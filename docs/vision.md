# Pathloom

## Mission

Help people discover careers, identify skill gaps, and make informed career decisions through AI.

## Problem

People do not know:

- Which career fits them
- Which skills they need
- Which country offers opportunities
- What to learn next

## Solution

Pathloom combines:

- Career data
- Skills data
- Country requirements
- AI reasoning

to provide:

- Readiness scores
- Career roadmaps
- Skill gap analysis
- AI career coaching

## MVP Features

1. Career Explorer
2. Readiness Score
3. Skill Gap Analysis
4. Roadmap Generator
5. AI Chat
6. Resume Upload

August 2026
